## 一、为什么 v1 会被"还原"

AP2 打开"在线插件列表"时会做三件事：

| 序号 | 行为 | v1 的后果 |
|---|---|---|
| 1 | 下载 `scripts/psvita/autoplugin.lua`，`files.move` 覆盖到 `scripts/psvita/`，再 `dofile` 加载 | 本地已镜像化的脚本被官方原版顶掉 |
| 2 | 下载 `plugins/plugins.lua`，`files.move` 覆盖到 `plugins/` | 190 处镜像化 URL 中被还原 131 处 |
| 3 | 上述文件都来自 `raw.githubusercontent.com` | 网络一断，更新逻辑本身也跑不动 |

结论：v1 只改了文本，只要触发一次在线更新就回到原始状态。

## 二、v2 的三层防覆盖设计

```text
L1 静态镜像    18 个 lua、190 处 GitHub URL 统一前置 https://gh-proxy.com/
L2 运行时 hook script.lua 最前端劫持 http.get / http.download，出口统一改写
L3 覆盖拦截    plugins_online.lua 里的两处 files.move 覆盖动作全部改道
```

### L2：运行时 Hook（核心）

注入位置：`script.lua` 第 23 行，早于 `dofile("git/shared.lua")` 及所有业务脚本加载。

```lua
if not __CN_MIRROR_HOOK then
    __CN_MIRROR_HOOK = true
    local __MIRROR = "https://gh-proxy.com/"
    local __PFX = { raw.githubusercontent.com/ github.com/ api.github.com/ objects.../ codeload.../ }
    -- http.get / http.download 被包装：命中 GitHub 域名 → 前置镜像；非 GitHub 域名原样放行
end
```

特性：
- 整个 AP2 进程内所有 http 出站请求都过这一层，包括官方后来下载的新版脚本里写的原始域名；
- 已带镜像前缀的 URL 不会二次叠加；
- `devdavisnunez.x10.mx` 等非 GitHub 域名不动；
- 整段包在 `pcall` 里，即使掌机环境的 http 表不可写，也不会导致 AP2 启动失败（此时退化为 L1 + L3）。

### L3：覆盖动作改道

`scripts/psvita/plugins_online.lua` 第 219 / 238 行：

| 原行为 | v2 行为 |
|---|---|
| `files.move(tmp, "scripts/psvita/")` 覆盖 autoplugin.lua | 改为 `files.delete(tmp)`：官方下载内容直接丢弃，继续 `dofile` 本地已镜像化脚本 |
| `files.move(tmp, "plugins/")` 覆盖 plugins.lua | 改为写入 `plugins/plugins_online_cache.lua` 并加载该缓存，`plugins/plugins.lua` 本体永不被动 |

效果：在线更新只更新"在线列表数据"，不再触碰任何已打补丁的脚本。

## 三、安装

### 方式 A：整包覆盖安装（推荐）

1. 把 `AutoPlugin2_2.20_CN_v2.vpk` 拷到记忆卡任意目录；
2. VitaShell 里选中安装，装到与原 AP2 相同的分区（原装 ux0 就装 ux0）；
3. 覆盖安装保留 `ux0:data/AUTOPLUGIN2/` 下的配置与插件备份。

### 方式 B：FTP 手工覆盖（不重装）

1. 先确认 AP2 安装位置：`ux0:app/AUTOPLUG2/` 或 `ur0:app/AUTOPLUG2/`；FTP 路径绝对写法 `/ux0:/app/AUTOPLUG2/`；
2. 把 `patch_lua_v2/` 内 18 个 lua 按同名相对路径覆盖进去，**必改的两个**：
   - `script.lua`（L2 hook）
   - `scripts/psvita/plugins_online.lua`（L3 改道 + URL 镜像）
3. 其余 16 个是 URL 镜像文件，一并覆盖更彻底。

## 四、验证方法

1. 打开 AP2 → 进"在线插件"列表，列表能刷出来即 L1/L2 生效；
2. 进设置，手动触发一次"检查脚本更新/语言更新"，退出重进，列表仍能刷新 → L3 生效；
3. 用 FTP 看 `ux0:app/AUTOPLUG2/scripts/psvita/autoplugin.lua` 的修改时间没被刷新 → 覆盖拦截生效；
4. 若第 1 步失败：镜像本身不可用，按下节换镜像重打。

## 五、边界与注意事项

| 场景 | 结果 |
|---|---|
| 在线列表/在线更新（本文讨论的覆盖） | 已拦截，补丁不会被还原 |
| AP2 提示"本体有新版本"并执行升级 | 会整体替换 `app/AUTOPLUG2/`，补丁全失效。升级后需用本补丁包重打，建议在设置里先关掉自动更新 |
| 在线语言包更新 | 只换 `lang/` 文本，不含网络逻辑，不影响补丁 |
| 免费镜像关停 | 改 `build_patch_v2.py` 顶部 `MIRROR` 重打包；或直接把 L2 hook 里的 `__MIRROR` 字符串换成新镜像 |
| 掌机 TLS 兼容性 | 装后列表仍加载失败时，改用整机 Wi-Fi 代理指向电脑 `192.168.10.2:7890` 作为保底 |
